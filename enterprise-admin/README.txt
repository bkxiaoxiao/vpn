Relay 企业网络管理后台 UI 原型

这是本地交互设计稿。Relay 是暂定产品名；RitFit 为演示组织名。
未连接飞书、供应商、代理节点或真实员工；未部署到 Google Cloud Run。
数据在浏览器 localStorage 中保存。演示输入的订阅地址不会被保存或请求。

查看方式
  直接在浏览器打开 preview.html（单文件交互预览）。
  或在本目录运行：python3 -m http.server 4180 --bind 127.0.0.1
  然后访问 http://127.0.0.1:4180

编辑方式
  index.html：页面骨架与导航。
  style.css：字体、颜色、布局、响应式与弹窗样式。
  app.js：演示数据、页面、交互与浏览器本地存储。
  preview.html：由上述三个源文件合并生成，修改源文件后需要重新生成。

设计方向
  浅色控制台、森林绿主色、低饱和辅助色与细分隔线。
  左侧组织导航；顶部面包屑；页面操作区、主内容与辅助状态。
  表格承载资源和权限；卡片组织资源池；发布页面展示版本与同步状态。
  窄屏收起导航文字，保留带可访问名称的图标；表格局部横向滚动。

页面范围
  总览：资源总量、节点健康、员工授权、同步率与团队连接趋势。
  订阅与节点：按格式分类、搜索筛选、导入弹窗、资源详情与模拟同步。
  资源池：新建、选择来源和编辑授权范围。
  员工与设备：搜索员工、分配资源池、调整访问状态。
  配置发布：版本概览、四个平台设备示例、发布、回滚与发布动态。
  审计记录：记录演示操作、搜索与 CSV 导出。
  工作空间设置：组织、飞书、设备上限、同步间隔、离线策略和部署信息。

交互边界
  图表、健康、员工总量、设备总量与回执数是固定演示指标，不表示实时监控。
  新订阅在演示中显示为“待接入”，不会伪造已解析节点。
  模拟同步只更新演示时间，不进行实际节点探测。
  发布和回滚演示会增加版本并写入审计；完整策略快照、发布记录与真实回执待后端接入。
  部门范围目前使用文本演示，正式版本应由飞书组织树及员工选择器提供稳定 ID。
  恢复初始数据入口位于工作空间设置。

后续 Cloud Run 接入边界
  UI 文件可作为服务端静态资源提供；采用何种服务端框架待实际开发时确定。
  localStorage 替换为鉴权 API；密钥、上游地址、身份校验和资源解析在服务端执行。
  资源数据、会话、发布版本和审计需要外部持久化，不能依赖 Cloud Run 实例本地文件。
  定时订阅刷新及异步任务应通过适当的外部调度/任务机制实现。
  管理员授权、飞书 OAuth 回调、CSRF 防护及供应商 URL 校验需要在后端实现。
  节点流量承载与控制台服务分开设计，本原型未实现代理网关。
