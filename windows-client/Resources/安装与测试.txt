Relay 企业连接 0.1.2 · Windows x64 测试版

适用 Windows 10 / Windows 11 x64（Intel / AMD）。本包自带 .NET 桌面运行时及 sing-box，无需另装 .NET。

安装：运行 Relay-Enterprise-0.1.2-Windows-x64-Setup.exe，按当前用户安装。升级前先退出旧版，等待系统代理恢复。
便携版：完整解压 Portable.zip 后运行 RelayEnterprise.exe，不要只复制单个 EXE。首次运行会注册当前用户的飞书登录回调；移动文件夹后请从新位置重新运行客户端。

默认企业服务：https://vpn-243359801139.asia-east1.run.app
1. 点击“通过飞书登录”，在默认浏览器完成企业飞书授权；允许浏览器返回 Relay。
2. 管理员须启用员工、分配资源池并发布配置。没有分配线路时登录仍可成功，连接按钮保持禁用。
3. 同步后选择线路并连接。连接后可继续选择其他已授权线路，已有连接可能短暂重连。
4. 首次连接检测每条线路的延迟，之后每小时更新；超时或失败显示“超时/不可达”。检测不改变当前线路。
5. 退出或断开时恢复此前系统代理。异常结束后看护进程会停止核心，并尝试恢复本程序接管的系统代理。

严格身份要求：
没有匿名模式、测试账号、原始订阅导入或跳过飞书的入口。
授权码只交给服务端。客户端使用 PKCE 校验短期一次性票据，只在内存中保存设备访问令牌；重开必须重新登录。
连接、切换线路前在线校验授权；运行时每 30 秒校验、约每 5 分钟同步配置。撤权、过期或控制服务不可达时停止代理。
本地控制接口仅监听 127.0.0.1，使用每次运行生成的随机密钥，不对局域网开放。

系统代理：
勾选接管时，仅影响遵循当前用户 Windows 系统代理的程序。本版不是全设备 TUN VPN，不承诺所有应用或 UDP/QUIC 自动代理。
已有 PAC 时拒绝自动接管，可取消该开关，用显示的本地 HTTP/SOCKS 端口测试指定应用。
如果异常关闭后仍无法联网，重开客户端并点击“恢复系统代理”。其他代理程序修改了设置时，本程序会保留恢复记录，避免静默覆盖。

用量：外购节点直连模式不提供可信的企业员工用量计量。需要企业网关及采集器后才能显示网关侧实际用量。

本安装包尚未进行 Windows Authenticode 签名。它是内部测试包；Windows 首次打开时可能显示发布者或信誉提示。
不要向客户端、聊天或员工发送飞书 App Secret。包内不含生产节点或飞书密钥。
安装、真实飞书登录、系统代理接管/恢复与供应商节点连通性需要在目标 Windows 电脑上验收。
